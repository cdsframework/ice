# Supported Vaccines

This file contains the current ICE-supported vaccine reference from the ICE
Implementation Guide. It is maintained separately so accepted CVX codes,
vaccine-group mappings, notes, and caveats can be updated without revising
the main implementation guidance.

See the [proposed ICE Implementation Guide](../implementation/ICE_Implementation_Guide.md)
for message structure and integration guidance.
