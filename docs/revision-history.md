# Documentation Revision History

This history summarizes meaningful changes to the documentation released with ICE 2.60.1 and subsequent releases. The
[legacy Implementation Guide](archive/ICE-Implementation-Guide-distrib.pdf) and its
[tracked-changes copy](archive/ICE-Implementation-Guide-distrib-trackchanges.pdf) are retained here; consult the tracked-changes
copy for earlier guide revisions. These files are historical; use the [technical documentation index](README.md) for current
documentation.

For software changes and upgrade actions, see the [ICE Release Changelog](release-changelog.md).

| ICE Version | Documentation Changes |
|-------------|-----------------------|
| 2.61.1 — November 12, 2026 | Added the root overview and linked it with the technical index; updated series-output configuration guidance and examples; corrected environment-based override instructions; added an HPV age-9 recommendation override example for both HPV series; added the release changelog and this history; retained the legacy guide and tracked-changes PDF; updated FHIR R6 implementation, output configuration, client integration, migration, code-value, disease, and schedule-authority guidance; updated pneumococcal supplemental text; added ICE Downloads links; reorganized the vMR input-node table for readability; clarified FHIR schedule-authority output; updated the FHIR contextual-condition code-system URL. |
